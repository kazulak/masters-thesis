# Historical synthesis entrypoint

Current figures and tables are built by [thesis/reporting](../reporting/README.md).
The former synthesis framework, intermediate publication CSVs and superseded
figures were retired after the complete reporting set passed the release audit.
No accepted evidence was deleted.

For the old generator, tests and assets, use the
[accepted evaluation revision](https://github.com/kazulak/masters-thesis/tree/c7c6cac0b55bdff2f4c24b70397b36f89bedc45f/thesis/synthesis).
Historical commands in frozen records must be run in that historical checkout,
not against the current tree. The original software and data identities remain
in each evidence package and the [release provenance](../../release/provenance.json).

The [unified-v4 historical entrypoint](unified_v4/README.md) preserves links from
accepted records. See the [audit](../../release/AUDIT.md) for retirement validation.
